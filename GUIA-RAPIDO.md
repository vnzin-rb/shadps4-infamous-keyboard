# Guia rápido — inFAMOUS Second Son

## Abrir o jogo

Extraia o ZIP inteiro, abra **Iniciar_Jogo.cmd** e selecione o `eboot.bin` do seu jogo. Configure seus próprios módulos de sistema em `user/sys_modules` quando necessário. Jogo, firmware e saves não acompanham o download.

## Touchpad

| O jogo pede… | Faça isto |
| --- | --- |
| Seta para cima | Segure **1** |
| Seta para baixo / destruir torre de tiro | Segure **2** ou **P** |
| Seta para esquerda | Segure **3** |
| Seta para direita | Segure **4** |
| Um toque no lado esquerdo | Segure **Delete** |
| Um toque no lado direito | Segure **Page Down** |
| Dois dedos / dois lados ao mesmo tempo | Segure **Delete + Page Down** juntos |
| Toque no centro / clique comum | **Espaço** |

Use **1, 2, 3 e 4 da fileira de cima**, não os números do teclado numérico. Cada deslize leva 0,3 segundo: segure por aproximadamente meio segundo e solte. Se a cena pedir para manter o dedo, continue segurando até terminar.

Exemplos: diante da torre de tiro, segure **P** e solte. Se uma interação pedir subir e manter o dedo enquanto usa R2, mantenha **1** pressionado e use **O** (letra O) como R2. Para outro sentido, siga a seta mostrada na cena.

Os atalhos funcionam sem mouse. As setas do teclado ↑ ↓ ← → continuam sendo o **direcional do controle**. **Insert** alterna o modo touchpad pelo mouse; não é necessário para os atalhos acima.

## Spray

1. Segure **G**: virar de lado.
2. Continue com G e segure **H** por 1–2 segundos: chacoalhar.
3. Solte H e continue com G.
4. Aperte **F6** uma vez: mirar movendo o mouse.
5. Segure **O** e mova o mouse: pintar.
6. Ao terminar, solte O e G e aperte F6 novamente.

## Outros controles

| Comando | Teclas |
| --- | --- |
| Mover personagem | **W A S D** |
| Câmera / analógico direito | **I J K L** |
| X / Círculo / Quadrado / Triângulo | **N / B / V / C** |
| L1 / R1 | **Q / U** |
| L2 / R2 | **E / O** |
| L3 / R3 | **X / M** |
| Options | **Enter** |
| Direcional | **↑ ↓ ← →** |
| Tela cheia / pausar / FPS | **F11 / F9 / F10** |

G e H devem ficar pressionados durante a ação. F6 e Insert ligam/desligam modos. Para trocar teclas, edite `user/input_config/CUSA00004.ini`; se usar perfil unificado, edite `default.ini`. **F8** recarrega os mapeamentos no jogo.

O gesto para baixo na torre foi confirmado em jogo. As novas teclas de cima e dos lados passaram nos testes automáticos; a aceitação em cada cena ainda deve ser verificada pelo jogador.
