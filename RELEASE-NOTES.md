# v1.0.0 — touchpad e spray pelo teclado

Build Windows x64 baseada na AYOUB1080p, com:

- **1**: deslize para cima.
- **2 ou P**: deslize para baixo.
- **3**: deslize para esquerda.
- **4**: deslize para direita.
- **Delete + Page Down**: dois dedos independentes simultâneos.
- **G / H / F6 / O**: virar, chacoalhar, mirar com o mouse e pintar.

Segure a tecla de deslize por cerca de meio segundo. Se o jogo pedir para manter o dedo, continue segurando até terminar a ação. Use os números da fileira superior.

**Como abrir:** baixe `shadps4-infamous-keyboard-windows-x64.zip`, extraia tudo, abra `Iniciar_Jogo.cmd` e selecione o `eboot.bin` do seu jogo. O QtLauncher é opcional e pode usar o mesmo core.

O ZIP inclui o executável, runtimes, perfil limpo e guia rápido. Não inclui jogo, firmware, módulos de sistema, chaves ou saves. Configure seus próprios módulos quando necessário. Confira a integridade em `SHA256SUMS.txt`.

**Validação:** 17.702 verificações automáticas passaram. O gesto para baixo na torre foi confirmado por um jogador em CUSA00004. Os novos atalhos de cima e dos lados foram testados automaticamente; a aceitação em cada cena ainda depende de teste em jogo.
